01About

I'm a Regional Technical Analyst at the First Nations Health Authority, where I support network and cloud infrastructure across regional offices and remote clinics — Cisco switches, VeloCloud SD-WAN, Palo Alto firewalls, and the Microsoft 365 / Azure environment underneath it all.
